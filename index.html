Why CamHost

Everything you need. Nothing you don't.

Built for developers, creators, and anyone who needs reliable, private file storage without the subscription fees.

♾️
Truly Unlimited Storage
No storage caps, ever. Telegram's infrastructure handles everything — we just route your files there securely.
🔒
Private & Secure
Files go to your private Telegram bot channel. Only you have access. Downloads are proxied through the server to keep your bot token hidden.
⚡
Fast Uploads
Upload directly from your browser with real-time progress tracking. Supports files up to 2 GB (with Local Bot API server).
📂
File & Folder Manager
Organize your uploads into folders. Search, sort, rename, move and delete files from a beautiful dashboard interface.
🤖
Telegram Powered
Leverages Telegram's rock-solid, globally distributed infrastructure. Your files are safe even if our servers go down.
🌐
Self Hostable
100% open source. Deploy it on your own server with full control. MIT licensed — fork it, modify it, make it yours.
How it Works

Simple by design.

Three steps from upload to anywhere-access.

01
Upload from Browser
Drag & drop any file into the dashboard. No software to install — works entirely in your browser.
02
Telegram Stores It
Our PHP backend securely forwards your file to a private Telegram channel using the Bot API. The file ID is saved to your account database.
03
Access Anytime
Browse, search, organize into folders, and download your files from the dashboard — from any device, anytime.
